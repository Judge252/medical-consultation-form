# TheClinic — טופס ייעוץ ובדיקה רפואית

יישום Node.js/Express קל משקל לטופס רפואי בעברית ובכיוון RTL. הטופס מאמת את הנתונים בדפדפן ובשרת, יוצר קובץ PDF מסוג A4 בזיכרון בלבד ושולח אותו כקובץ מצורף באמצעות Resend.

## דרישות

- Node.js 20 ומעלה
- חשבון Resend פעיל ושולח מאומת

## הפעלה מקומית

1. התקנת תלויות:

   ```bash
   npm install
   ```

2. יצירת קובץ `.env` מקומי על בסיס `.env.example` והגדרת הערכים הנדרשים:

   - `RESEND_API_KEY`
   - `RESEND_FROM`
   - `RESEND_TO`
   - `PORT` — אופציונלי; ברירת המחדל היא `3000`

3. הפעלת השרת:

   ```bash
   npm start
   ```

4. פתיחת `http://localhost:3000` בדפדפן.

Puppeteer מוריד Chromium תואם בזמן `npm install`. בסביבה שבה Chromium מנוהל ומותקן בנתיב אחר, ניתן להגדיר גם את המשתנה האופציונלי `PUPPETEER_EXECUTABLE_PATH`.

אין להציב מפתחות API בקוד, ב-HTML או ב-JavaScript של הדפדפן. כתובת המייל המוצגת בטופס וב-PDF היא פרטי הקשר של הקליניקה; יעד השליחה נקבע אך ורק באמצעות `RESEND_TO`.

## בדיקות

```bash
npm test
```

הבדיקות משתמשות במשלוח דוא״ל מדומה, בודקות דחיית נתונים לא תקינים, מייצרות PDF אמיתי עם נתוני דמה בעברית ומוודאות שמניעת שליחה כפולה פועלת. הן אינן שולחות דוא״ל אמיתי.

## נקודות קצה

- `GET /health` — בדיקת תקינות מינימלית.
- `POST /submit-form` — אימות, יצירת PDF ושליחה.

## פרטיות ואבטחה

- רשומות רפואיות אינן נכתבות לדיסק ואינן נשמרות בדפדפן.
- ה-PDF נוצר בזיכרון ומצורף ישירות להודעה.
- תוכן רפואי מלא אינו מועתק לגוף המייל.
- השרת מגביל את גודל בקשת ה-JSON, מאמת את כל השדות ומבצע escaping לפני יצירת HTML.
- אין Analytics, אחסון מקומי או סקריפטים מצד שלישי.
